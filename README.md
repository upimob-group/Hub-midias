# hub-midias

Mídias públicas já aprovadas para publicação nas redes do **HUB Imobiliário** ([hubimobiliario.group](https://hubimobiliario.group)).

O Instagram exige que cada imagem publicada pela API esteja em um link público; este repositório serve só para isso. Não guarde aqui nada que não vá ser publicado (dados de clientes, documentos, contratos ou arquivos da plataforma).

- `grid-estreia/` — as 24 artes do grid de estreia do @hubimobiliario.group, numeradas na ordem de publicação.
- `reels/` — os 3 Reels da série "HUB na prática" (MP4, 9:16) e as capas, para a semana de lançamento.
